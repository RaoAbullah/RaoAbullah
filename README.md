### 🌟 Featured Engineering Projects

#### 1. 🤖 [TadbeerAI 2.0](https://github.com/RaoAbullah/tadbeer-ai) — Trilingual Financial Inclusion Multi-Agent Platform
> **Alibaba Cloud AI Hackathon National Finalist (Top 300 / 16k+)**
- **Architecture:** LangGraph multi-agent pipeline with deterministic supervisor routing and parallel specialist agents (Economic Intelligence, Personal Finance, Risk Stress-Testing).
- **Zero-Hallucination Math:** Python `Decimal` arithmetic engine computing 5-Pillar Financial Health Scores (0–100) and expense shock simulations with 100% precision.
- **Resilience & Testing:** Gemini-primary / Groq-fallback registry for zero-downtime inference; Flutter mobile app backed by **654 automated tests (100% pass rate)**.
- **Tech Stack:** `Python`, `LangGraph`, `Gemini API`, `Groq`, `Flutter`, `Dart`, `Firebase`, `World Bank API`, `PBS SPI Feed`

#### 2. ⚡ [RaftFS](https://github.com/RaoAbullah/raftfs) — Fault-Tolerant Distributed Consensus Storage Engine
> **Distributed Systems & Consensus Algorithm**
- **Consensus & Quorum:** Implemented Raft distributed consensus with randomized election timers, strict majority quorum ($\lfloor N/2 \rfloor + 1$), and SHA-256 cryptographic block integrity.
- **High-Speed MapReduce Search:** Parallel MapReduce query engine concurrently searching cluster nodes and deduplicating results in **sub-70ms**.
- **Self-Healing & 3D Visualizer:** Automated node recovery with catch-up synchronization in **<2.5s**; built interactive **Three.js WebGL 3D dashboard** with real-time cluster state and Chaos Monkey fault-injection controls.
- **Tech Stack:** `Node.js`, `TypeScript`, `Three.js`, `WebGL`, `MapReduce`, `Docker`, `WebSockets`

#### 3. 🛰️ [GeoRisk-AI](https://github.com/RaoAbullah/fyp_project) — Satellite Geospatial Desertification Forecasting Engine
> **Final Year Engineering Capstone Project**
- **Earth Observation Data:** Ingested multi-spectral satellite feeds (Sentinel-1 SAR, Sentinel-2 Optical, NASA MODIS, TerraClimate) via Google Earth Engine API across all 30 Sindh districts.
- **Feature Engineering:** Extracted 20+ bioclimatic feature vectors (NDVI, SAVI, NDWI, MSI, EVI, LST, SAR backscatter, precipitation).
- **Deep Learning Benchmarks:** Evaluated CNN, LSTM, Deep MLP, and Temporal Transformers to forecast multi-year land degradation vulnerability (2025–2030) with an automated FastAPI reporting engine.
- **Tech Stack:** `Python`, `FastAPI`, `Google Earth Engine (GEE)`, `TensorFlow`, `XGBoost`, `Rasterio`, `PostgreSQL/PostGIS`

#### 4. 🎙️ [PrepMaster](https://raoabullah.github.io/Interviewpractice/) — AI Interview Simulator SaaS
> **Interactive Client-Side Web Application**
- Role-based question generator with timed 30-second preparation periods and in-browser audio/video recording.
- Engineered 100% client-side recording via native WebRTC MediaRecorder API ensuring privacy with zero cloud bandwidth costs.
- **Tech Stack:** `JavaScript (ES6+)`, `Supabase Auth`, `WebRTC MediaRecorder API`, `HTML5/CSS3`

#### 5. 🛡️ [GuardPulse](https://github.com/RaoAbullah/guard-pulse) — Fail-Safe Multi-Channel GLOF Warning Concept
> **Scholarly Presentation at DecentraSec & ACM Symposium (UN SDG 13)**
- Dual-signal verified warning architecture protecting vulnerable communities in Gilgit-Baltistan from Glacial Lake Outburst Floods.
- Multi-channel notification pipeline utilizing SMS fallback, solar sirens, and mosque public address networks.
